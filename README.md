# Sistema de Gerenciamento de Tarefas (CLI)

Aplicação simples em Python desenvolvida no Google Colab para gerenciamento de tarefas via linha de comando (CLI).

## 🚀 Funcionalidades
- **Adicionar Tarefa:** Permite cadastrar novas tarefas com descrição.
- **Visualizar Tarefas:** Lista todas as tarefas cadastradas e seus status.
- **Marcar como Concluída:** Altera o status de uma tarefa específica.
- **Remover Tarefa:** Exclui uma tarefa da lista.

## 🛠️ Tecnologias e Ferramentas
- Python 3.x
- Google Colab (`.ipynb`)
